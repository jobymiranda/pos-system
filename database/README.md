# SimplePOS Database

The `pos_system.sql` file contains the MySQL schema and sample data
required by Technical Formative Assessment 2.

## Tables

- `customers`
- `users`

Each table contains at least five sample records.

## Import Instructions

1. Start Apache and MySQL through XAMPP.
2. Open `http://localhost/phpmyadmin`.
3. Create a database named `pos_system`.
4. Select the database.
5. Open the Import tab.
6. Choose `database/pos_system.sql`.
7. Click Import.
